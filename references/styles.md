# Style presets

只加载用户选中的风格规则。共享的确认门、配音、字幕、BGM、双封面、发布和复盘流程仍以 `SKILL.md` 与 `workflow.md` 为准。

## `qingyunguan-blackgold`：青云观黑金国风

### 视觉身份

- 使用近黑背景、克制的铜金轮廓与局部金光；以年轻、清俊、造型稳定的道士作为连续身份锚点。
- 使用中国线描、雕刻光感，不做写实古装剧；最亮金色只给手部、能量符号或唯一语义焦点。
- 粒子缓慢稀疏，避免游戏特效堆叠。
- 每屏只表达一个概念：四至六字文学短句、一个简短白话解释、一个稳定人物或象征动作。

### 生成与连续性

- 使用 `scripts/ark_images.py` 与 `scripts/ark_video.py`；场景可用 `远景|`、`近景|`、`围合|` 前缀。
- 每条提示重复人物年龄、面部气质、服装、黑金线描、克制金光等身份锚点，并明确景别、姿势、手部动作、能量位置和负面约束。
- 先生成静帧并确认，再生成动态片段；不复制对标账号的独特镜头序列或提示词结构。
- 最终中文文字在本地渲染，不让生图模型生成准确标题。

### 字体、封面与音频

- 正文使用暖白大字，必要时用朱砂红强调；解释文字必须在手机缩略尺寸可读。
- 品牌印章位置在同一账号内保持稳定。
- 从同一张已确认、无烘焙文字的原帧分别制作 3:4 和 4:3 封面；不得拉伸人物，两个比例都要独立检查脸、手和金色焦点。
- 沿用配置中的 MiniMax 音色和手工 BGM 包络：开头较强、正文恒定降低、结尾渐强并淡出；默认移除生成片段环境声。

## `qingxuguan-ink`：青虚观水墨国风

### 文案与来源

- 从静心、自持、止语、不争、守时、取舍、守拙等现实情绪切入，生成紧凑命令、悖论对照或问题到结果型标题。
- 核验古籍归属；短引原文并标明出处，转述时写成“可理解为”。不得把现代网文冒充《道德经》《庄子》《鬼谷子》或道藏内容。
- 旁白使用原创、节奏化的四至六字文学短句；现代白话解释单独作为屏幕文字，禁止拼入 TTS 输入。
- 搜索成稿中最独特的钩子和句子；如长片段高度匹配，重写论点顺序、比喻、句式和结尾，不能只换同义词。

### 视觉层级与动画

- 使用 Remotion 的确定性逐帧动画；将纸墨底图、远层灰字、中层手稿、近层黑字、标题、倒影、字幕、解释和石印拆成独立层。
- 水中倒影必须从原层沿明确水线镜像并裁切在水线下方；扰动只作用于倒影区域。镜像连接点对齐原字视觉基线，不能漂到解释文字下方。
- 图层顺序保持：后方大笔刷标题 → 标题倒影 → 前景魏碑标题 → 白话解释。只反射后方大标题，不反射前景魏碑文字。
- 使用颜色明度让后方标题退后，不用透明度、发光、投影或模糊伪造层级。
- 字幕优先使用同次 MiniMax 合成时间戳；以帧保存 `from`、`to`、短句、揭示帧、高亮字和解释。转换后检查空隙与重叠。

### 封面与验证

- 注册独立封面构图，不随便截取首帧。标题、解释和石印保持在竖版信息流中央安全区。
- 使用暗手稿纹理、100% 不透明的深朱砂大笔刷后标题、暖白与亮朱砂的前景魏碑标题、靠近标题组的解释，以及不规则低饱和朱砂石印。
- 先渲染代表静帧，再渲染含背景运动、倒影与字幕切换的 5–6 秒样片；每版只修改一个视觉维度。
- 在全尺寸与三列信息流缩略图尺寸同时检查：倒影连接、字幕可读性、背景克制程度、解释距离和石印质感。

## 风格隔离

- 黑金风格不得自动加入水墨手稿、水面倒影或魏碑封面系统。
- 水墨风格不得自动加入黑金人物、金色能量、Ark 卡片式镜头或人物中心裁切规则。
- 用户明确要求混搭时，记录为跨风格实验，并在生成付费资产前确认一次。
